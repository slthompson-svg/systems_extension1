Words to know

System of equations
Two or more equations that use the same variables.
Solution of a system
An ordered pair (x, y) that makes every equation true.
Point of intersection
The point where two lines cross. It is the solution.
Slope-intercept form
y = mx + b. m is the slope and b is the y-intercept.
Standard form
Ax + By = C, with both variables on one side.
Coefficient
The number multiplied by a variable. In 4x, the coefficient is 4.
Substitution
Replacing a variable with an equal expression.
Elimination
Adding or subtracting equations so one variable cancels out.
Parallel lines
Same slope, different y-intercepts. They never cross: no solution.
Coincident lines
The same line written two ways: infinitely many solutions.
Lesson 1 · 8.FGR.7.2

What is a solution to a system?

Every point on a line makes that line's equation true. The point where two lines cross is on both lines, so it makes both equations true. That point is the solution.

Line explorer

Move the sliders to change each line. Watch the violet point. Then test your own point below.

Test a point

How to check a solution

  1. Substitute the x-value and the y-value into Equation 1.
  2. Simplify. Is the equation true?
  3. Do the same thing for Equation 2.
  4. If both are true, the point is a solution. If even one is false, it is not.
Example: Is (2, 3) a solution?
1y = 2x − 1
2y = −x + 5
3 = 2(2) − 1 → 3 = 3 ✓ 3 = −(2) + 5 → 3 = 3 ✓ Both are true, so (2, 3) is the solution.
Watch out
  • An ordered pair is always (x, y). Don't switch them.
  • A point that works in only one equation is not a solution. It is only on one line.
Lesson 2 · 8.FGR.7.3

Solve by graphing

Graph both lines on the same coordinate plane. The point where they cross is the solution. Graphing works best when the answer has whole-number coordinates.

Steps

  1. Write each equation in slope-intercept form, y = mx + b.
  2. Plot the y-intercept b on the y-axis.
  3. Use the slope m = rise ÷ run to find more points. Draw the line.
  4. Repeat for the second line.
  5. Find the point where the lines cross. Write it as (x, y).
  6. Check the point in both equations.
Watch out
  • A negative slope goes down as you move right.
  • Slope ½ means up 1, right 2. Not up 2, right 1.
  • If the crossing point is between grid lines, graphing only gives an estimate. Use substitution or elimination to get the exact answer.
Lesson 3 · 8.FGR.7.4

Solve by substitution

If one equation tells you what a variable equals, put that expression into the other equation. Then you have one equation with one variable, which you already know how to solve.

Steps

  1. Get one variable alone in one equation (it may already be alone).
  2. Substitute that expression into the other equation. Use parentheses.
  3. Solve the new equation. It has only one variable.
  4. Put that value back into an equation to find the other variable.
  5. Write the solution (x, y) and check it in both equations.
Best time to use substitutionA variable is already alone, like y = 3x − 2 or x = 4y + 1, or it has a coefficient of 1.
Watch out
  • Use parentheses when you substitute: 2(3x − 2), not 2 · 3x − 2.
  • Distribute to every term inside the parentheses.
  • Don't stop after finding one variable. A solution needs both x and y.
Lesson 4 · 8.FGR.7.4

Solve by elimination

Add or subtract the equations so one variable cancels out. This works because adding equal amounts to both sides of an equation keeps it balanced.

Steps

  1. Line up both equations in standard form: x under x, y under y, = under =.
  2. Look for opposite coefficients, like +2y and −2y. If there are none, multiply one equation (or both) to make them.
  3. Add the equations. One variable cancels.
  4. Solve for the variable that is left.
  5. Substitute it back into an original equation to find the other variable.
  6. Check in both equations.
Watch out
  • When you multiply an equation, multiply every term, including the number after the equals sign.
  • If the coefficients are the same (like 3y and 3y), subtract, or multiply one equation by −1 first.
Lesson 5 · 8.FGR.7.2, 8.FGR.7.4, 8.PAR.3.2

One solution, no solution, or infinitely many

Two lines can cross once, never cross, or lie on top of each other. Compare slopes and y-intercepts to know which one before you solve.

SlopesY-interceptsGraphNumber of solutionsWhat algebra shows
DifferentAnyLines cross onceOne solutionx = a number, y = a number
SameDifferentParallel linesNo solutionVariables cancel, false statement like 3 = −1
SameSameSame lineInfinitely manyVariables cancel, true statement like 0 = 0

Two examples

No solution
1y = 2x + 3
2y = 2x − 1
Both slopes are 2. The intercepts are 3 and −1. The lines are parallel. Substitute: 2x + 3 = 2x − 1 → 3 = −1That is false, so there is no solution.
Infinitely many solutions
1y = 2x + 3
24x − 2y = −6
Solve Equation 2 for y: −2y = −4x − 6, so y = 2x + 3. It is the same line. Substitute: 4x − 2(2x + 3) = −6 → −6 = −6That is always true, so there are infinitely many solutions.
Watch out
  • "No solution" and "the solution is (0, 0)" are different answers.
  • Equations can look different and still be the same line. Always rewrite in y = mx + b to compare.
Lesson 6 · 8.FGR.7.1

Systems in context

Many real problems have two unknowns and two facts. Each fact becomes an equation. Solve the system, then explain what the numbers mean.

Steps

  1. Define the variables. Write "Let x = …" and "Let y = …".
  2. Write one equation for each fact. Look for totals (how many) and values (how much money).
  3. Solve with the method that fits best.
  4. Interpret. Answer the question in a full sentence with units.
  5. Check that the answer makes sense. Can you sell −3 tickets?
"Total" problemsTickets, coins, snacks: one equation counts items (x + y = total), one adds up money.
"When are they equal?"Gym plans, savings: both are y = rate · x + start. Set them equal.
GeometryPerimeter 2L + 2W, plus a sentence like "the length is 5 more than the width."

Algebra I preview

Parallel and perpendicular lines

Compare slopes. This is part of 8.FGR.7.5.

  • Parallel: same slope. Example: y = 3x + 1 and y = 3x − 4.
  • Perpendicular: slopes are negative reciprocals. Their product is −1. Example: slope 2 and slope −1/2.
  • Neither: any other pair of slopes.
Negative reciprocalFlip the fraction and change the sign. ⅔ → −3/2. −4 → 1/4.

Systems of linear inequalities

An inequality like y > x − 2 is true for a whole region, not just a line. The solution of a system of inequalities is where the shaded regions overlap.

  1. Graph each boundary line. Use a dashed line for < or > and a solid line for ≤ or ≥.
  2. Shade above the line for y > or y ≥. Shade below for y < or y ≤.
  3. The overlap is the solution. Test a point to check.
Test (0, 0)0 > 0 − 2 → 0 > −2 ✓0 ≤ −2(0) + 4 → 0 ≤ 4 ✓(0, 0) is in the overlap, so it is a solution.

Choosing the best method

GraphingGood for seeing the answer and for estimating. Use it when both equations are in y = mx + b form and the answer is likely a whole-number point.
SubstitutionGood when a variable is already alone or has a coefficient of 1 or −1.
EliminationGood when both equations are in standard form, especially when coefficients are opposites or easy to make opposite.

Algebra I problems often need elimination with both equations multiplied. Try Level 3 on the Elimination page, and the break-even problems on In context.

Small group

  • Start every lesson with the walkthrough player. Turn on Narrate for read-aloud, and pause on each step to ask "what comes next?"
  • Keep students on Level 1 until they get three in a row on the first try. The score line tracks this on each device.
  • The Read aloud button in practice reads the problem, which helps with word problems.
  • The color code is consistent: blue is always Equation 1, orange is Equation 2, violet is the solution. Ask students to use matching colored pencils on paper.
  • Feedback names the mistake: switched x and y, or a point that is only on one line.

Co-taught classes

  • Stations: one teacher runs Graphing with the line explorer on the board, while students rotate through Substitution and Elimination practice.
  • Midterm review: assign Mixed review. Each student reports their score and the lessons the summary tells them to revisit.
  • Extension: students who finish early move to Algebra I preview and Elimination Level 3.
  • Problems are randomly generated, so students sitting together get different numbers.
NotePractice scores are saved only in each student's own browser. They are not sent to the teacher. Have students show the score line or the Mixed review summary screen.
